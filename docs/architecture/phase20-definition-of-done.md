# Phase 20 Definition of Done

Implementation DoD:

- production coordinator committed,
- persistent/idempotent run state tested,
- approval/blocker/verifier truth tested,
- learning hooks verifier-gated,
- readiness evidence separation tested,
- repository guard, lint, full test suite, build and production health green,
- PR merged to main,
- canonical project state reconciled.

Operational DoD is separate and requires the post-implementation real-world validation plan.
