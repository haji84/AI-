# Phase 20 verified integration hooks

`ProductionAutonomyHooks` intentionally receives only verifier-backed cycle/completion reports. Composition code may fan these events into existing memory, skill, team, continual-learning, telemetry and Phase 19 candidate-generation adapters.

The coordinator does not directly mutate those subsystems because their existing promotion/evidence policies remain authoritative. In particular, a Phase 20 completion hook may submit a candidate to Phase 19, but cannot promote it directly.
