# 公開情報からの成果物作成

実際の公開GitHub APIからOllamaの版・公開日時・公式ページを取得し、[CSV](ollama-release.csv)と[確認メモ](ollama-release.md)を作成した。[実行記録](actual-run.json)に通常入口、Goal/契約、正規WorkStateの検証記録、独立再取得、成果物ハッシュ、時刻を保存している。

検証用の依頼から成果物の確認まで1,892ms。これはこの有限な検証依頼の実測であり、GORIQ全体の開発・納品時間ではない。新しいCognitiveServiceで再開してもファイルは書き直されず、保存内容と再取得した対象項目を照合できた。取得対象外のJSON項目が変化しても、正規の過去検証記録で原本の出典・時刻・両ファイルのハッシュを保持する。対象値、Goal、設定、ファイルが変わると拒否する。

今回の実データ実行はモデルを使わない明示的な検証であり、`actualAiSelection=false`。直前のモデル有効な実行も、Windowsコミット使用量が既存85%上限を超え、モデル呼び出し前に代替処理へ移行したため、実AI成功として認めていない。両記録・成果物を保全し、上限は変更していない。

新しい能力は既存の`CognitiveService`のホスト設定`publicResearch`から利用する。ホストがGoalに結び付けたmanifest、隔離された出力先、許可済み公開URL・項目のsourcePolicyを渡す。モデルは登録済みの操作IDだけを選ぶ。答え・本文・期待値を渡して変換する仕組みではない。未設定は拒否し、HTTPやモデル入力から権限を追加しない。グローバル設定、本番サービス、認証情報は変更していない。

独立レビューで不正な暦日を受け入れる問題も発見し、失敗を再現して修正した。模擬データによるテストと、ここにある実データの証拠は区別する。ハッシュ参照は署名ではなく、過去記録の信頼境界は既存の正規Compass WorkStateである。

未達: 実AIによる選択、署名付き自律開発Job・修正・次Job、未設定の自然言語からの汎用的な調査先発見、GORIQ全341要件の完成。今回の有限な成果物作成を、それらの完成とは扱わない。独立Verifier鍵のHuman Gate、旧GoalのHOLD、別件停止状態を維持する。
