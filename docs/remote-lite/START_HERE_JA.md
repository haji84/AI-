# GORIQ Remote Lite 導入案内（受入試験用）

この候補は未署名です。友達への正式配布用ではありません。
署名済み製品、運営するHTTPS接続先、外出先からの実機受入が揃ってから、
次の手順で導入します。現在の候補だけを渡しても利用開始できません。

## 用意するもの

- 操作されるWindows PCまたはAndroidと、その端末の所有者。
- 操作するPCまたはiPhoneのブラウザ。
- 運営者から案内された接続先と、自分専用のログイン情報。

GORIQ本体、Tailscale、RustDesk、開発ツールやルーターの設定は、
利用者の導入手順には含みません。他人のログイン情報は共有しないでください。

## Windowsを追加する

1. 正式版の提供元・署名を確認してインストーラーを開きます。
   現在のユーザーのみに導入します。既存のホストは更新前に終了します。
   セキュリティ警告が出たら、保護を解除せず提供元に確認してください。
2. スタートメニューの「GORIQ Remote Lite」を開きます。
3. 所有者の操作画面で自分の端末用の招待を作り、PCの登録画面で
   「招待を確認する」を押します。表示された接続先を確認して
   「この接続先へ端末を登録する」を押します。
4. PCに表示された鍵の確認コードと所有者側の表示を全文照合し、
   その端末だけを承認します。PCで「所有者の承認を確認する」を押し、
   保存完了後に「設定を終了する」を押します。
5. 先に操作元の端末一覧から接続を要求し、要求の有効時間内に
   Windowsのホストを再度開きます。Windows側に表示されたセッションの
   画面・入力許可を確認し、開いたローカル画面で「接続を待つ」を押します。
   初期設定やインストールだけで、画面共有は開始されません。

Windowsの電源・通信・通常のログイン済み画面が必要です。ロック画面、
UAC画面、保護された画面は操作できません。現候補は接続ごとの本人許可と
時間制限があり、無人での再起動復帰は受入未完了です。

## Androidを追加する

正式に署名された専用APKと対応機種一覧の公開を待ってください。
`debug`、`physicaltest`、「公開通信試験」のAPKは通常配布版ではありません。

専用アプリで自分の招待先へ登録し、確認コードを全文照合します。
その後「操作権限の設定を開く」からOSのユーザー補助を本人が許可します。
接続時は「画面共有の設定を開く」→「接続要求を確認する」と進み、
対象セッションを確認してOSの画面共有を許可します。

現在、遠隔入力の受入対象はAndroid14以降です。Android9〜13も同等に
操作できるとは確認されていません。ロック・再起動・共有終了後は、
OSの許可が再び必要になる場合があります。「常に無人で許可」は提供しません。

## 操作と終了

操作元で自分の端末を選び、最新の映像が表示されてからタップ・スワイプ・
マウス・キー入力を行います。終わったら「切断」を押します。
Androidは画面共有通知からも停止できます。

初回受入では、別回線から実画面の変化、入力結果、切断後の映像・入力停止を
確認します。ログイン画面が表示されたことだけでは遠隔操作の合格になりません。

## つながらないとき

- 「承認待ち」: 所有者側で対象の確認コードを照合して承認します。
- 招待が期限切れ: 所有者側で以前の申請が未登録か確認してから、
  同じ鍵を保持した再申請手順を使います。アプリのデータを消去しないでください。
- 接続先が変わった: 表示を確認し、提供元へ連絡してください。
  別の接続先へ登録を勝手に置き換えないでください。
- 映像や入力が止まった: 端末の電源・通信・ロック・OS共有状態を確認します。
  入力結果が不明な操作を続けて送らず、一度切断して確認します。
- 外の回線だけつながらない: 運営者へ接続時刻と症状を伝えます。
  中継経路が必要な場合があります。ポート開放や保護機能の解除は不要です。

## 更新・削除

接続を終了し、ホストを閉じてから提供元の新しい署名済み版へ更新します。
同じ版番号の別ファイルで上書きしないでください。
Windowsの「インストールされているアプリ」から削除しても、端末登録情報は
保持する設計です。端末を手放すときは所有者画面で登録解除も行います。
Androidのデータ消去・アンインストールは鍵を失う場合があるため、
登録解除や再導入の案内を確認してから行ってください。

## この候補に残る受入

ライセンスはWindowsのインストール先にある`REMOTE_LITE_LICENSE.txt`、
Androidの「ライセンス」画面から確認できます。Go/WebRTC等の第三者の条件も保持します。

WindowsインストーラーのCI結果、正式署名、クリーンな実機への初期導入、
外出先PC→Android、iPhone携帯回線→Windows、公開TURN、通信断・再起動復旧、
約40台同時操作の確認が必要です。`candidate.json` の
`distributable: false` を配布可能に読み替えないでください。
