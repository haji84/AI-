# Agent Handoff Contract

Every handoff must contain:

TASK_ID
SOURCE_AGENT
TARGET_AGENT
STATUS
OBJECTIVE
SCOPE
FILES_ALLOWED
FILES_FORBIDDEN
ACCEPTANCE_CRITERIA
TESTS_REQUIRED
RESULT
BLOCKERS
NEXT_ACTION

Do not rely on informal chat history for project state. GitHub issues, PRs, PROJECT_STATE and repository documentation are authoritative.
